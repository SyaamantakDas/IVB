        About IVB

        IVB is an unofficial planner and is not connected with Indian Railways or IRCTC. It covers the Vande Bharat network as it ran in late 2026. Timetables were checked on 6 November 2026 against the sources linked on each train, and days off differ between sources for a few trains. Check NTES or IRCTC before you book.

        How it works

        Connections search every route for journeys on Vande Bharats alone, allowing a change of station by road within a city. Circuits are laid out day by day around each train's day off. The season chart scores each start date by how many nights fall in each place's best months.

        Data

        Routes and halts from Railway Board circulars, Wikipedia and railway timetable sites; station positions and the map from DataMeet and the Survey of India outline. The code and data are open, so corrections can be sent as changes to the data files.
